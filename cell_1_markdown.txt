# Извлечение сущностей и событий из набора текстов

## Цель работы
В этом ДЗ вы научитесь извлекать структурированную информацию (сущности, события и отношения) из текстов с помощью методов NER и Information Extraction. Вы примените локально развернутые языковые модели для решения реальных задач (юридические, медицинские, новостные данные), оптимизируете производительность моделей и разработаете простое приложение, демонстрирующее извлечение данных.

## Датасет
**CUAD (Contract Understanding Atticus Dataset)**
- URL: https://huggingface.co/datasets/theatticusproject/cuad
- 13,000+ размеченных коммерческих контрактов (41 категория)
- Рекомендуется использовать 1K-2K примеров для CPU обработки

## Локальные модели
1. **Llama-2-7B-Chat** - универсальная модель для английского языка
2. **Mistral-7B** - эффективная модель с хорошим качеством
3. **Saiga-7B** - модель для русского языка

## Извлекаемые сущности
- PERSON - имена людей
- ORG - организации
- MONEY - денежные суммы
- DATE - даты
- CONTRACT_TYPE - тип контракта
- OBLIGATION - обязательства
- JURISDICTION - юрисдикция

## Этапы выполнения

### 1. Локальное развертывание (35%)
- Развернуть 2-3 модели локально
- Сравнить производительность quantized vs full precision
- Успешный запуск локальных моделей

### 2. Оптимизация производительности (30%)
- Реализовать batch processing
- Оптимизировать inference (quantization, caching)
- Измерить throughput на подвыборке

### 3. Качество извлечения (25%)
- Точность NER/IE на специализированном домене
- Обработка edge cases

### 4. Анализ и сравнение (10%)
- Benchmark инференса
- Понимание trade-offs между скоростью и качеством

## Критерии оценки
- **Локальное развертывание**: 35%
- **Оптимизация производительности**: 30%
- **Качество извлечения**: 25%
- **Анализ и сравнение**: 10%
- **Бонусы**: +5-15% (streaming, custom quantization, parallel extraction)

Для CPU обработки: 500-1K примеров
